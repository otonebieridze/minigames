# MiniGames

Responsive single-page web application for browsing games, built as part of the [RS School Short Track](https://rs.school/courses/short-track) course.

## Tech Stack

- TypeScript (strict mode)
- Vite
- Sass
- No frameworks or CSS libraries — plain HTML/CSS/TS, per course requirements
